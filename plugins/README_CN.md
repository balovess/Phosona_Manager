# Phosona Manager 插件使用指南

插件可以为 Phosona Manager 增加可选功能，例如过滤网页请求、发现浏览器资源，或将浏览器扩展与下载管理器配合使用。

[English](README.md)

## 安装插件

1. 打开“设置 → 插件”。
2. 选择“添加插件”。
3. 选择一个 `.zip`、`.xpi` 或 `.crx` 插件包。
4. 查看开发者、安装包指纹和所需权限。
5. 确认安装。插件初始为禁用状态，权限也不会自动开启。

请不要安装来源不明的插件。只有在理解每项权限用途后，才应安装对应插件。

## 权限选择

权限会逐项显示。根据具体能力，你可以选择“仅允许一次”“允许当前会话”“始终允许”或“不允许”。

常见权限包括：

- 访问指定网站；
- 在你确认后创建下载任务；
- 在用户操作后读取或写入剪贴板；
- 读取或写入指定文件夹；
- 显示通知或更新系统托盘状态。

权限默认拒绝，你可以随时在“设置”中撤销。插件包内容发生变化后，应用会将其视为新版本，并要求重新确认权限。

## 两种插件类型

Phosona 声明式插件只包含规则和设置，不执行插件 JavaScript，适合用于请求过滤等功能，也是更安全的选择。

兼容的 Chrome 和 Firefox 扩展也可以加载，但必须使用兼容的 Manifest V2 或 V3 安装包。这类扩展运行在浏览器扩展环境中，并标记为“原生兼容”。由于 Electron 不提供全部 Chrome 或 Firefox API，某些扩展可能只能部分工作，或无法加载。

## 常见问题

- 插件无法加载时，请检查安装包是否有效，以及所有必需权限是否已批准。
- 如果你不想授予某项权限，可以保持拒绝，插件的其他功能仍可能继续使用。
- 插件包发生变化后，需要重新查看并确认权限。
- 如果下载引擎或插件安全服务暂时不可用，插件能力会暂时关闭；普通下载和浏览仍可继续。
