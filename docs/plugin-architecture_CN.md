# 插件权限说明

本页用用户能够理解的方式说明插件权限如何工作。

[English](plugin-architecture.md)

## 插件默认没有权限

安装插件不会自动授予它浏览器、文件、剪贴板、下载或网络请求权限。所有权限初始都是“不允许”。你可以启用插件，但不必批准它请求的全部权限。

每项权限都会说明用途，并在适用时显示网站或文件夹范围。允许访问一个网站不会同时允许访问其他网站；允许访问一个文件夹也不会允许访问设备上的其他位置。

## 权限有效期

- **仅允许一次**：当前操作结束后失效。
- **当前会话**：应用会话结束后失效。
- **始终允许**：在你撤销或插件包发生变化前保持有效。
- **不允许**：禁止使用对应能力。

撤销一项权限不会影响其他无关权限。插件包内容发生变化后，原有的长期授权会被清除，方便你重新检查新版本。

## 插件可以做什么、不能做什么

根据你批准的权限，插件可能可以观察指定网页请求、创建经你批准的下载、显示通知、在用户操作后使用剪贴板，或访问指定文件夹。

插件不能任意使用 Node.js 或 Electron API，不能运行 Shell 命令，不能打开任意本地文件，也不能悄悄扩大网站或文件夹范围。当前版本不向插件提供进程和 Shell 执行能力。

## 隐私和审计信息

插件页面会显示已授予的权限，并展示经过脱敏的重要判定，例如请求被阻止或文件夹访问被拒绝。审计信息不会记录剪贴板内容、文件内容、Cookie、令牌或 URL 查询参数。

如果插件安全服务不可用，插件能力会安全关闭，而不是获得更大的权限。普通浏览和下载功能不会因此被关闭。

## 更新和删除插件

插件更新需要保持相同的插件身份并递增版本。新增权限或扩大网站范围时，需要重新确认。你可以随时在“设置”中禁用或删除插件。

安装步骤见[插件使用指南](../plugins/README_CN.md)。Chrome 和 Firefox 扩展的行为见[浏览器扩展兼容性](webextension-compatibility_CN.md)。
